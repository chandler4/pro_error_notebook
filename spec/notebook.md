## 功能需求（FR）

### 功能域 A：错题录入

| 编号 | 需求（EARS） |
|---|---|
| FR-A1 多图上传 | 当用户在新增页拖拽或点选图片时，系统应支持一次上传多张图片（≤6 张、单张 ≤10MB、jpg/png），并允许为每张图片标注「题目图/解答图」角色 |
| FR-A2 裁剪去干扰 | 当图片包含干扰内容（相邻题目、边角等）时，系统应支持人工框选有效区域，仅上传裁剪结果（上传前压缩，长边 ≤2000px） |
| FR-A3 AI 解析 | 当用户点击开始解析时，系统应调用多模态 AI，按错题数据结构识别字段，生成含题干、标准答案、知识点、解析的草稿；标准答案与解析：图中已有则提取图中内容，图中无则由 AI 自行解题生成（2026-11-13 chandler 确认；禁思考下解题质量波动接受，由 FR-A6 分项确认人工把关） |
| FR-A4 解析失败兜底 | 当 AI 解析失败（自动重试 1 次后仍失败）时，系统应返回明确错误，并允许用户重试或转手动填写 |
| FR-A5 草稿暂存 | 当解析完成时，系统应将草稿以待确认状态（PENDING_CONFIRM）暂存于服务端，支持用户找回继续编辑 |
| FR-A6 分项确认 | 当用户逐项核对修改草稿并点击确认时，系统应校验必填项（科目、题干）后将错题正式录入错题列表 |
| FR-A7 仅题目图直接解析 | 当用户仅上传题目图（无解答图、题面亦无解答痕迹）时，系统应直接解析——题面信息照图提取，标准答案与解析由 AI 自行解题生成（v2.3 策略，图中优先），生成内容经分项确认人工把关后入库，解析与确认流程不因此阻塞 |

### 功能域 B：错题管理与输出

| 编号 | 需求（EARS） |
|---|---|
| FR-B1 分科列表 | 当用户进入错题记录时，系统应按科目分页 Tab（数学/物理/化学，可随枚举扩充）列表展示已确认错题 |
| FR-B2 搜索筛选 | 当用户输入题目文字或知识点条件时，系统应支持模糊搜索、分页显示、查询与重置 |
| FR-B3 详情/编辑/删除 | 当用户查看、编辑、删除错题时，系统应分别提供抽屉式详情、复用新增页的编辑模式、以及二次确认后的硬删除（记录与图片一并删除） |
| FR-B4 导出 | 当用户选择导出时，系统应按当前筛选条件导出 Markdown 或 PDF（PDF 支持遮盖答案的重做模式） |
| FR-B5 备份迁移 | 当用户在数据备份页操作时，系统应提供全量 JSON 导出，以及导入（跳过已存在/覆盖更新两种模式，行级错误报告） |
| FR-B6 标签标注 | 当用户在录入或编辑错题时，系统应支持手工添加多个自由文本标签用于归类（与知识点语义独立：知识点=学科知识、标签=自定义归类，无字典约束、AI 不自动生成） |
| FR-B7 标签筛选 | 当用户在错题列表按标签筛选时，系统应返回标签模糊匹配的错题列表 |

### 功能域 C：质量与运行（2026-11-11 追加，切面日志）

| 编号 | 需求（EARS） |
|---|---|
| FR-C1 切面日志 | 当任意 REST 业务接口被调用时，系统应经 AOP 切面记录请求参数、业务返回内容全文、成功状态、错误码与耗时，并持久化到 business_log |
| FR-C2 AI 返回记录 | 当 AI 调用发生时，系统应记录模型返回原文、请求摘要、模型名与耗时（不得记录 API 密钥） |
| FR-C3 运行日志查看 | 当用户在运行日志页查询时，系统应支持按类型（业务操作/AI 调用）、模块、成功状态、时间筛选并分页查看记录全文 |
| FR-C4 日志可靠性 | 当业务日志入库失败时，系统应保证业务主流程不受影响（仅转系统运行日志告警） |

## 非功能约束

- 简单易用：单机部署、单用户免登录、仅本机监听（127.0.0.1）
- 数据结构化、可迁移：导入导出与本数据结构完全一致
- **AI 仅在录入解析环节调用**（FR-A3/A4），其余链路零 AI 依赖
- 新技术栈/中间件引入必须评审通过后集成（评审记录见技术架构选型表）
- Web 端 Vue 实现、后台 Spring Boot 实现、AI 层 Java 统一实现（OpenFeign + 防腐层）

## 附录：原始场景记录（2026-11-11 原文，供追溯）

**场景设计**

1、web应用端左侧含有多个菜单项

错题记录菜单

--tab分科，数学，物理，化学

a、每科成列表显示，可通过题目文字模糊搜索，支持知识点搜索，分页显示，支持查询和重置

b、支持新增，新增打开新页面，支持手动拖拽图片到图片区域，支持多个图片(有些题目图片和解答分开，答案可能在答题纸上)，点击录入后，解析原题信息

同时调用api进行题目解析，把相关错题原信息及解析信息，能够分项显示，等待用户确认，确认完成，录入错题列表

**原切面日志条款（2026-11-11 16:13 追加，现归纳为 FR-C1~C4）**

- 后端采用 AOP 切面统一记录业务操作日志：REST 接口请求与业务返回内容、耗时、成功状态与错误码
- 业务日志持久化到数据库（business_log 表），与系统运行日志（logback 文件）并存，永久保留
- AI 调用必须记录模型返回原文与业务返回内容，形成质量查看记录
- 提供运行日志查询页面（左侧菜单），支持按类型（业务操作/AI 调用）/模块/成功失败/时间筛选
- 日志不得记录 API 密钥等敏感信息；日志入库失败不得影响业务主流程
