## 2. 页面规格

### P1 错题记录（/questions）

| 区块 | 元素 | 说明 |
|---|---|---|
| 分科 Tab | 数学/物理/化学（读 `meta.enums.subjectTabs`） | 切换携带科目重新查询（TC-L-07） |
| 待确认入口 | Tab 行右侧「待确认 (N)」链接 | 点击切换**草稿列表视图**（同页复用表格：题干预览/创建时间/操作[继续编辑·删除]）；再点切回 |
| 搜索区 | 题干模糊输入、知识点输入、**标签输入（FR-B7）**、查询、重置 | 重置清空并回 page=1（TC-L-06） |
| 工具栏 | ＋新增错题、导出 | 导出打开弹窗（见 §2.6） |
| 表格 | 题干（两行截断）/题型/**知识点+标签合并列**（标签灰底虚线样式区分）/来源+题号/错题日期/操作 | 操作：查看（抽屉）·编辑（跳新增页编辑模式）·删除（二次确认） |
| 分页 | 共 N 条、页码、每页 10 | API 3.5 |
| 空态 | 「暂无符合条件的错题，点击右上角新增录入」 | — |

**API 映射**：GET /api/v1/questions（3.5）；GET /api/v1/questions/drafts（3.8）；DELETE /api/v1/questions/{id}（3.7）、DELETE /api/v1/questions/drafts/{id}。

### P2 新增/编辑三步流（/questions/new[?id=]）

- **步骤1 上传**：拖拽/点选多图（≤6 张）；缩略图角色徽标（题目图/解答图，点击切换）；「裁剪」弹窗（框选有效区域）；「删除」；无图时「开始解析」禁用。前端完成压缩（长边 ≤2000px）。
- **步骤2 解析中**：loading（预计 10~60s）；失败态：错误信息 + 重试 + 转手动填写。
- **步骤3 分项确认**：基本信息（科目*/年级/题型/来源/题号/错题日期）、题干*（多行）、图片预览、标准答案（可增删多行）、知识点（标签增删 + **归并提示**：输入 ≥1 字联想已有知识点，点选复用，也可自由输入）、**标签（FR-B6：自由多标签，回车添加、无联想，与知识点语义独立，AI 不自动生成）**、解析（Markdown/LaTeX 多行）。底部：确认录入、返回上一步。
- **完成态**：成功页（返回列表 / 继续录入下一题）。
- **编辑模式**（?id=）：预填现有数据直接进入步骤3；题干旁提供「重新解析」按钮（可换图回到步骤1）。**重新解析语义（2026-11-12 确认）**：parse 生成新草稿/新 errorQuestionId，confirm 新记录成功后**前端联动 DELETE 旧记录**，不产生重复（TC-N-06）。
- **草稿续编**：从 P1 待确认入口 →「继续编辑」跳转本页 ?id= 直达步骤3。

**状态机**：`上传 →(≥1图+点击解析)→ 解析中 →(成功)→ 确认 →(校验通过)→ 完成`；`解析中 →(失败)→ 失败态 →(重试)→ 解析中 | (转手动: POST questions/drafts 建空草稿)→ 确认(空草稿)`；`确认 →(返回)→ 上传(图保留)`。

**API 映射**：parse-image（3.1）→ parse（3.2）→ confirm（3.3）；转手动填写 POST questions/drafts（3.8，2026-11-12 补）；编辑 PUT questions/{id}（3.6）；归并候选 meta/knowledge-points（3.11）。

### P3 运行日志（/logs）

| 区块 | 元素 |
|---|---|
| 筛选区 | 类型下拉（全部/业务操作/AI 调用）、模块模糊、成功状态、日期区间、查询/重置 |
| 表格 | 类型徽章（OPERATION 蓝 / AI_CALL 橙）/模块/操作描述/成功✓失败✗/错误码/耗时ms/时间 |
| 详情抽屉 | 请求内容 + 返回内容（AI 返回/业务返回**全文**，等宽字体展示，可复制） |
| 空态 | 「暂无日志」 |

**API 映射**：GET /api/v1/logs（3.12；本接口自身不产生日志）。

### P4 数据备份（/backup）

| 区块 | 元素 |
|---|---|
| 导出卡片 | 「导出全量 JSON」按钮 + 说明（结构与规约一致、含已确认错题） |
| 导入卡片 | 文件上传（≤20MB JSON）+ 模式单选（跳过已存在 skip / 覆盖更新 overwrite）+ 开始导入 |
| 结果报告 | total / inserted / skipped / overwritten 计数 + 行级错误明细表（行号+原因） |

**API 映射**：GET /api/v1/backup/export、POST /api/v1/backup/import（3.10）。

### §2.6 页内容器

- **详情抽屉**（P1 查看）：图片区（多图横向，角色角标）、题干、标准答案（编号列表）、知识点标签、解析（Markdown 渲染，DOMPurify 消毒）、元信息（科目/年级/题型/来源/题号/日期）。
- **导出弹窗**（P1 工具栏）：格式单选（Markdown/PDF）、重做模式开关（仅 PDF，说明文案：遮盖答案、答案页置尾）、当前筛选条件摘要、导出按钮（下载反馈）。

## 3. 异常与空态清单

| 场景 | 表现 |
|---|---|
| 空列表/空草稿/空日志 | 各页空态文案 + 引导动作 |
| 上传：类型/大小/数量超限 | 即时提示（41001/41002/41003 对应文案） |
| 解析失败 | 步骤2 失败态（重试/转手动） |
| 确认必填缺失 | 字段标红 + 提示（subject/questionStem） |
| 导入错误 | 行级明细表展示 |
| 接口错误码统一 | request 封装按 code 弹 toast，120s 超时仅解析接口 |
