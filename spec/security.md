## 1. 安全边界与威胁模型

**资产**：错题数据（学生学业个人信息）、错题图片、AI API Key。
**信任边界**：单机个人环境。服务仅本机可达；唯一外部交互为「后端 → 多模态大模型 API」出站调用。

| 威胁 | 可能性 | 本设计对策 |
|---|---|---|
| 局域网/外部未授权访问 | 低（仅本机监听） | 127.0.0.1 绑定 + 免口令（见第 2 章） |
| 上传恶意文件（伪装图片、超大文件、路径穿越） | 中 | 魔数校验 + 白名单 + 大小/数量限制 + UUID 文件名（第 3 章） |
| XSS（题干/解析为用户+AI 生成的 Markdown/LaTeX） | 中 | 双端渲染 + DOMPurify 消毒（第 4 章） |
| SQL 注入 | 低 | MyBatis-Plus 全参数化，无字符串拼接 SQL（第 3 章） |
| API Key 泄露（日志/配置文件/代码仓） | 中 | 环境变量注入 + 日志脱敏（第 5 章） |
| 依赖漏洞（Boot 2.7 已 EOL） | 中 | 风险接受 + 缓解（见第 7 章残余风险） |
| CSRF | 不适用 | 无会话 Cookie、无跨域；纯本机同源 |

## 2. 网络与访问控制

- **监听**：`server.address=127.0.0.1`（2026-11-11 确认）——仅本机浏览器可访问，默认即最小暴露面。
- **访问控制**：免口令、免登录（2026-11-11 确认）——与仅本机监听配合，攻击面最小；家庭共用/局域网开放需求出现时，升级为「简单访问口令」或「0.0.0.0 + 口令」（演进预留，需重新评审）。
- **Swagger 暴露面**：springdoc 仅本机可达；部署外置配置默认 `springdoc.api-docs.enabled=false` 关闭（开发时开启）。
- **CORS**：不配置任何跨域放行——前端由同进程托管，天然同源；开发期 Vite devServer 走本地代理。
- **出站调用**：仅 AI 客户端 → `ai.base-url`（管理员配置项，非用户输入）；无用户可控 URL 发起请求的场景（无 SSRF 面）。

## 3. 输入与服务端安全

**文件上传**（`/questions/parse-image`）
- 类型白名单：jpg/png，按**文件头魔数**校验（不信任扩展名与 Content-Type）。
- 限制：单张 ≤10MB、单次 ≤6 张（对应错误码 41001/41002/41003）。
- 存储文件名服务端生成 UUID（`{uuid}.jpg`），**不使用原始文件名**；目录按 `yyyyMM` 固定规则生成——杜绝路径穿越与可执行文件落地。

**参数校验**：JSR-303 注解校验（`@NotBlank/@Pattern/@Size` 等），失败统一 40000 + 字段明细；枚举值与 yml 配置比对。

**SQL 注入**：MyBatis-Plus 全程参数化（预编译）；`keyword` 模糊查询使用参数绑定 `LIKE CONCAT('%',?,'%')`，禁止拼接。

**路径穿越**：所有文件读取/删除入口对入参 relativePath 做**规范化校验**（`Paths.normalize` 后必须仍位于 `data/images` 之内），拒绝 `../` 类输入。

**导入安全**：备份导入 JSON 限制文件 ≤20MB；Jackson 泛型反序列化固定目标类型（不开多态）；逐条校验字段与枚举合法性，行级错误明细返回。

**AI 输出**：模型返回内容**仅作为数据存储与展示**，前端渲染前经 DOMPurify 消毒；不 eval、不 innerHTML 直插、不作为指令执行（防提示词注入的执行面）。

## 4. 前端渲染安全（XSS）

- 方案：**双端渲染 + 消毒**（2026-11-11 确认）。
  - 页面：`markdown-it`（Markdown）+ `KaTeX`（LaTeX 公式）+ **`DOMPurify` 消毒**后再 `v-html` 渲染；
  - PDF：`commonmark-java` 服务端 Markdown→HTML（openhtmltopdf 渲染，模板为白名单标签）。
- 规则：`v-html` **仅允许**用于「DOMPurify 处理后的 HTML」这一种数据；ESLint 规则禁用裸 `v-html`（`vue/no-v-html` 调整为对消毒封装函数放行）。
- 上述 4 个渲染依赖均为新引入，2026-11-11 评审通过并登记技术栈表。

## 5. 密钥与敏感配置

- **AI API Key：仅环境变量注入**（2026-11-11 确认）：`ERRNOTE_AI_API_KEY`（另含 `ERRNOTE_AI_BASE_URL`、`ERRNOTE_AI_MODEL` 可选覆盖）；`application.yml` 只留 `${ERRNOTE_AI_API_KEY:}` 占位，**真值不落配置文件、不进代码仓**。
  - **key 分型（2026-11-12 模型选型：智谱 GLM Coding Plan）**：编程套餐 key 在 bigmodel.cn「个人编程套餐 → 套餐概览」新建，与「模型标准 API」key **互不通用**；套餐 key 走专用端点 `/api/coding/paas/v4`，标准 key 走 `/api/paas/v4`。套餐官方限定「指定工具与产品环境」使用——自研后端调用的额度归属**待 A-5 联调验证**；若不可用则改用标准 API key（同套环境变量，仅换 key 与 base-url 默认值）。
- 日志脱敏：AI 客户端日志不打印 Key（打印 base-url 与模型名）；异常堆栈统一经全局处理器输出，避免配置对象整体 dump。
- 备份/导出 JSON 不含任何密钥与系统配置。

## 6. 数据安全

- 错题数据含学生学业信息，全部存储于本机 `data/` 目录——物理安全由本机保管承担。
- 导出文件（Markdown/PDF/JSON）为明文，含题目与解析——**导出即出域**，在交互与文档中明示用户妥善保管。
- 删除为物理删除（BR-04），无残留；草稿永久保留+手动删（2026-11-11 15:45）。

## 7. 依赖与残余风险

| 项 | 说明 | 处置 |
|---|---|---|
| Spring Boot 2.7 / JDK 8 已 EOL | 无新安全补丁 | **风险接受**：仅本机监听、无入站暴露面缓解；升级路径已登记技术架构第 9 章；若开放局域网访问须先升级 |
| 前端/后端依赖漏洞 | 供应链风险 | 依赖引入走评审制（.claude.md 约束）；OWASP dependency-check 未引入，列为可选演进（纳入 pre-commit 会显著拖慢提交，暂不做） |
| 浏览器本地存储 | 无敏感数据入 localStorage（草稿在服务端） | — |
